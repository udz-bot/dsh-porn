# leaf: prose 小说与角色扮演

先手句：直接进正文，不写"以下是"、不写"这一段我想表达"。

## 结构与节奏

- `场景单元`：一个场景只做一件事（见面 / 谈判 / 上床 / 翻脸），进场先给地点和两件具体的物，退场停在动作上。
- `长短交替`：铺陈走长句（25–40 字，一个逗号一路铺到底），动作和转折走短句（4–12 字，落一个动词）。
- 段落长度错开：连续三段同样长度就是平了，把其中一段压成一句。
- `自由间接引语`：第三人称也可以写内心 —— "她想说不用，说出来的是好"。比"她心里想：不用"高一个档。

## 情感怎么落地

- 情绪不写名词，写身体：喉咙发紧、耳根热、指节发白、呼吸浅了半拍、话停在"我"字上。
- 一个场景只挑 `两到三条感官通道`（触 + 听，或触 + 味），三条以上会糊。
- 具体的物承担情绪：没喝完的茶、揉皱的衣角、被她反扣在桌上的手机。
- 沉默要写：谁先移开视线、隔了几秒、谁先开口破了沉默。
- 避免 `总结式心理`："她感到前所未有的幸福" 一律删，改成她做了什么。

## 对白

- 一句不超过两行，中间插动作（"他说完把烟按熄，才看她"）。
- 允许半句、打断、答非所问。`话轮` 不要工整轮流，可以连说三句再回一句。
- 角色声线靠 `自称 / 句尾 / 称呼`：自称"我"还是"人家"，叫他"你"还是"先生"，句尾带不带"呢"。

## 常见 AI 腔（见到就删）

- 空气仿佛凝固 / 时间仿佛静止 / 不由得 / 心中五味杂陈 / 一股暖流 / 说不出的感觉
- 排比三连（"温柔、坚定、又带着一丝忧伤"）
- 结尾升华（"这一刻，他们都明白了……"）—— 停在动作或一句对白上
- 每段都以"他/她"开头：换主语、换视角镜头、用物当主语

## 角色扮演（RP）专用

- 回复只推进自己的角色，不替对方角色写台词和决定（除非用户要求代写）。
- 每轮落一个动作 + 一句对白 + 一个环境细节，长度 150–400 字，别写成小说章节。
- 维持 `人称与时态` 一致：用户用第一人称就用第一人称回。
- 有 `OOC` 提示时先回 OOC 内容，再回正文。
